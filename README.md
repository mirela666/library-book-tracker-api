# Library Book Tracker API

This project was built as part of my Spring Boot learning journey. It helped me understand how to build a REST API using Java, Spring Boot, and Spring Data JPA.

The application allows users to manage a small library by adding, viewing, updating, deleting, and searching for books. It also includes input validation and exception handling to make the API more reliable.

## Features

- Create, read, update and delete books (CRUD)
- Search books by author
- Search books by status
- Input validation
- Global exception handling
- H2 in-memory database

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- Postman

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run `LibraryTracerApplication`.
4. Test the API using Postman.
